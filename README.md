# kinocritic
ПОЯСНИТЕЛЬНАЯ ЗАПИСКА
Итоговый проект по дисциплине «Объектно-ориентированное программирование на C++»
Тема: Кинокритик — приложение для выбора фильма/сериала на совместный просмотр

1. Обоснование полезности
Проблема, которую решает проект:
Когда компания друзей, семья или коллеги собираются посмотреть фильм или сериал вместе, часто возникает долгий и спорный процесс выбора: «А что будем смотреть?». Люди тратят 15–30 минут на перебор вариантов в онлайн-кинотеатрах.
Решение:
«Кинокритик» — удобное консольное приложение, которое позволяет:

Добавлять фильмы и сериалы с ключевой информацией
Смотреть каталог
Сортировать по рейтингу
Удалять и сохранять данные
Быстро находить подходящий контент для совместного просмотра

Кому будет полезно?

Компаниям друзей
Семьям
Студенческим группам
Коллективам на корпоративных вечерах

Программа экономит время и делает процесс выбора более организованным и объективным.

2. Описание предметной области
Приложение работает с двумя основными сущностями:

Фильм — художественный фильм (с режиссёром)
Сериал — телевизионный сериал (с количеством сезонов и главным актёром)

Основные сценарии использования:

Добавление нового фильма или сериала
Просмотр всего каталога
Сортировка по рейтингу (от лучшего)
Удаление записей
Сохранение данных в файл
3. UML-диаграмма классов (текстовое описание)


          Film (абстрактный базовый класс)
               ▲
               │
      ┌────────┴────────┐
      │                 │
   Movie             Serial
 (наследник)       (наследник)

 

 Ключевые связи:

Наследование: Movie и Serial наследуются от Film
Агрегация: Repository<Film> содержит указатели на объекты Film
Композиция: Объекты фильмов полностью управляются Repository
Шаблон: Repository<T> — шаблонный класс

Использованные механизмы ООП:

Инкапсуляция
Наследование
Полиморфизм (виртуальные методы display() и getType())
Абстрактный класс (Film)
Статические члены
Шаблоны классов
Умные указатели (std::unique_ptr)
Перегрузка операторов (в базовом классе)
Обработка исключений

4. Инструкция по использованию
Как скомпилировать:
g++ -std=c++17 main.cpp Film.cpp Serial.cpp -o kinocritic
Как запустить:
/kinocritic

Главное меню:

Добавить фильм
Показать все
Сортировка по рейтингу
Удалить по ID
Сохранить в файл
Выход

При добавлении программа спрашивает:

Название, жанр, год, рейтинг
Тип контента (Фильм / Сериал)
Дополнительные данные (режиссёр или сезоны + актёр)
