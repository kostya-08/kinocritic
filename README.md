# kinocritic
ПОЯСНИТЕЛЬНАЯ ЗАПИСКА
Итоговый проект по дисциплине «Объектно-ориентированное программирование на C++»
Тема: Кинокритик — приложение для выбора фильма/сериала на совместный просмотр

1. Обоснование полезности
Приложение «Кинокритик» предназначено для удобного выбора фильма или сериала компанией друзей, семьёй или группой.
Решаемая проблема:
Часто при совместном просмотре тратится много времени на споры и поиск подходящего контента. Программа позволяет вести общий каталог фильмов и сериалов, быстро просматривать и сортировать их по рейтингу.
Полезность проекта:

Значительно экономит время при выборе
Помогает организовать просмотры
Удобен для совместного использования


2. Описание предметной области
Приложение работает с двумя типами объектов:

Фильм — художественный фильм (с режиссёром)
Сериал — телевизионный сериал (с количеством сезонов и главным актёром)

Основные функции:

Добавление фильма или сериала
Просмотр всего списка
Сортировка по рейтингу (от высокого к низкому)
Удаление по ID
Сохранение данных в файл


3. UML-диаграмма классов

                        ▲
                        │
               ┌────────┴────────┐
               │                 │
            Film              Serial

Использованные механизмы ООП:

Инкапсуляция — все поля приватные, доступ через методы
Наследование — Serial наследуется от Film
Полиморфизм — виртуальные методы display() и getType()
Шаблоны — шаблонный класс Repository<T>
Умные указатели — std::unique_ptr
Валидация данных — ограничение рейтинга (0–10) и года (1900–2026)


4. Инструкция по использованию
Компиляция:
Bashg++ -std=c++17 main.cpp Film.cpp Serial.cpp -o kinocritic
Запуск:
Bash./kinocritic
Главное меню:

Добавить фильм
Показать все
Сортировка по рейтингу
Удалить по ID
Сохранить в файл
Выход

Особенности ввода:

Рейтинг автоматически ограничивается диапазоном 0 — 10
Год автоматически ограничивается диапазоном 1900 — 2026
